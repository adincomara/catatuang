Setup Google OAuth Client ID

⚠️ Cara Menghilangkan Error 401 invalid_client:
  1. Buka console.cloud.google.com & pilih project.
  2. Masuk ke APIs & Services > Credentials > Create OAuth client ID.
  3. Pilih tipe: Web application.
  4. Tambahkan di Authorized JavaScript origins:
    https://money.adincomara.my.id
  5. Salin Client ID yang Anda dapatkan lalu tempel di kolom bawah ini.
